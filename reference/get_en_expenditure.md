# get_en_expenditure

Computes energy expenditure.as the share of the total expenditure by
decile

## Usage

``` r
get_en_expenditure(GCAM_version = "v7.1")
```

## Arguments

- GCAM_version:

  Main GCAM compatible version: 'v7.1' (default), 'v7.2', 'v7.0'.

## Value

\`energy_expenditure_per_clean\` global variable.
