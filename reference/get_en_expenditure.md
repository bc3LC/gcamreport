# get_en_expenditure

Computes energy expenditure.as the share of the total expenditure by
decile

## Usage

``` r
get_en_expenditure(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`energy_expenditure_per_clean\` global variable.
