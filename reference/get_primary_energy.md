# get_primary_energy

Retrieve primary energy consumption data by technology.

## Usage

``` r
get_primary_energy(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`primary_energy_clean\` global variable.
