# do_data_sample

Function to subset a dataset with the user's choices

## Usage

``` r
do_data_sample(
  sdata,
  sel_scen,
  sel_years,
  sel_cols,
  sel_vars,
  sel_reg,
  basic_reg,
  basic_vars
)
```

## Arguments

- sdata:

  dataset

- sel_scen:

  selected scenario/s

- sel_years:

  selected year/s

- sel_cols:

  selected column/s

- sel_vars:

  selected variables in tree

- sel_reg:

  selected regions in tree

## Value

subseted dataset
