# get_price_var_tmp

Retrieve price variables to compute carbon price.

## Usage

``` r
get_price_var_tmp(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`price_var\` global variable
