# get_co2_emissions

Combines CO2 emission queries into a single dataset.

## Usage

``` r
get_co2_emissions(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`co2_emissions_clean\` global variable.
