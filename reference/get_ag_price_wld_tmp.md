# get_ag_price_wld_tmp

Retrieve agricultural price index.

## Usage

``` r
get_ag_price_wld_tmp(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`ag_price_wld\` global variable
