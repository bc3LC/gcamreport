# get_fe_transportation_tmp

Retrieve mode-specific transport final energy, including rail, ship, and
domestic air.

## Usage

``` r
get_fe_transportation_tmp(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`fe_transportation\` and \`fe_transportation_raw\` global variables
