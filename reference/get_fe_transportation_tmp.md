# get_fe_transportation_tmp

Retrieve mode-specific transport final energy, including rail, ship, and
domestic air.

## Usage

``` r
get_fe_transportation_tmp(GCAM_version = "v7.1")
```

## Arguments

- GCAM_version:

  Main GCAM compatible version: 'v7.1' (default), 'v7.2', 'v7.0'.

## Value

\`fe_transportation\` and \`fe_transportation_raw\` global variables
