# get_food_availability

Computes Food availability

## Usage

``` r
get_food_availability(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`food_availability_clean\` global variable.
