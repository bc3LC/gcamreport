# get_co2_tech_emissions_tmp

Retrieves the non-bio CO2 emissions query by sector, subsector, and
technology.

## Usage

``` r
get_co2_tech_emissions_tmp(GCAM_version = "v7.0")
```

## Arguments

- GCAM_version:

  Main GCAM compatible version: 'v7.0' (default), 'v7.1', or 'v6.0'.

## Value

\`co2_tech_emissions\` global variable.
