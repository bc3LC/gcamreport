# get_ag_price

Calculate average mean for agricultural global index.

## Usage

``` r
get_ag_price(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`ag_price_clean\` global variable
