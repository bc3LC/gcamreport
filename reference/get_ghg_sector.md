# get_ghg_sector

Get sectorial GHG emissions.

## Usage

``` r
get_ghg_sector(GCAM_version = "v7.0", GWP_version = "AR5")
```

## Arguments

- GCAM_version:

  Main GCAM compatible version: 'v7.0' (default), 'v7.1', or 'v6.0'.

- GWP_version:

  Global Warming Potential (GWP) version: 'AR5' (default), 'AR6', or
  'AR4'.

## Value

\`ghg_sector_clean\` global variable.
