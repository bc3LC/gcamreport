# queries_general_v7.2

gcamreport queries compatible with GCAM 7.2 version. Contain all queries
except for nonCO2 queries

## Usage

``` r
queries_general_v7.2
```

## Format

vector

## Source

local

## Examples

``` r
if (FALSE) { # \dontrun{
library(gcamreport)
gcamreport::queries_general_v7.2
} # }
```
