# get_nonbio_tmp

Retrieves the non-bio CO2 emissions query by sector.

## Usage

``` r
get_nonbio_tmp(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`nonbio_diff\` global variable.
