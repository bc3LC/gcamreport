# get_expenditure

Computes food + energy expenditure.

## Usage

``` r
get_expenditure(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`expenditure_per_clean\` global variable.
