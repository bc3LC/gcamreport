# get_gross_co2_emiss

Retrieves the Gross CO2 emissions: Gross emissions of carbon dioxide
(CO2), not accounting for negative emissions from bioenergy with CCS
(BECCS) or agriculture, forestry and other land use (AFOLU)

## Usage

``` r
get_gross_co2_emiss(GCAM_version = "v7.1")
```

## Arguments

- GCAM_version:

  Main GCAM compatible version: 'v7.1' (default), 'v7.2', 'v7.0'.

## Value

\`gross_co2_emiss_clean\` global variable.
