# get_ag_production

Get agricultural production.

## Usage

``` r
get_ag_production(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`ag_production_clean\` global variable.
