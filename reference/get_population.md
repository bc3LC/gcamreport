# get_population

Retrieves the population query and converts units to millions.

## Usage

``` r
get_population(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`population_clean\` global variable.
