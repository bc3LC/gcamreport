# get_capital_stock

Retrieves Capital Stock data and converts units to 2010 USD.

## Usage

``` r
get_capital_stock(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`capital_stock_clean\` global variable.
