# get_gdp_mer

Retrieves GDP (MER) data and converts units to 10 USD.

## Usage

``` r
get_gdp_mer(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`GDP_MER_clean\` global variable.
