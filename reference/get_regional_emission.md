# get_regional_emission

Compute regional nonCO2 emission: regional production \* nonCO2 coef.

## Usage

``` r
get_regional_emission(GCAM_version = "v7.1")
```

## Arguments

- GCAM_version:

  Main GCAM compatible version: 'v7.1' (default), 'v7.2', 'v7.0'.

## Value

\`regional_emission\` global variable
