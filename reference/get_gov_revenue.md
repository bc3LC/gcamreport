# get_gov_revenue

Retreive overall carbon revenue.

## Usage

``` r
get_gov_revenue(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`gov_revenue_clean\` global variable
