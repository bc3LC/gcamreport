# get_se_trade_supply

Retrieve secondary energy trade supply data for calculating other
variables.

## Usage

``` r
get_se_trade_supply(GCAM_version = "v7.1")
```

## Arguments

- GCAM_version:

  Main GCAM compatible version: 'v7.1' (default), 'v7.2', 'v7.0', or
  'v6.0'.

## Value

\`se_trade_supply\` global variable.
