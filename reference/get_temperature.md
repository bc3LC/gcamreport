# get_temperature

Retrieves the global mean temperature query.

## Usage

``` r
get_temperature(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`global_temp_clean\` global variable.
