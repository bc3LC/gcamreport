# update_user_choices_plot

Update dataframe to display plots with the user's choices

## Usage

``` r
update_user_choices_plot(
  selected_scen,
  selected_years,
  tree_regions,
  tree_variables,
  sidebarItemExpanded
)
```

## Arguments

- selected_scen:

  user's selected scenarios

- selected_years:

  user's selected years

- tree_regions:

  user's selected regions

- tree_variables:

  user's selected variables

- sidebarItemExpanded:

  input sidebar expanded item
