# get_gdp_ppp

Retrieves GDP (PPP) data, computes regional GDP and annual GDPpc growth
rate, and converts units to 10 USD.

## Usage

``` r
get_gdp_ppp(GCAM_version = "v7.1")
```

## Arguments

- GCAM_version:

  Main GCAM compatible version: 'v7.1' (default), 'v7.2', 'v7.0'.

## Value

\`GDP_PPP_clean\` and \`GDP_PPP_pc_growth_clean\` global variables.
