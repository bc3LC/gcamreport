# get_consumption_hh

Compute share of total energy household consumption my decile

## Usage

``` r
get_consumption_hh(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`consumption_hh_clean\` global variables.
