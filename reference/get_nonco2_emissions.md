# get_nonco2_emissions

Retrieves non-CO2 emissions data.

## Usage

``` r
get_nonco2_emissions(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`nonco2_clean\` global variable.
