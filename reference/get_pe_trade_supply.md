# get_pe_trade_supply

Retrieve energy trade supply data for calculating other variables.

## Usage

``` r
get_pe_trade_supply(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`pe_trade_supply\` global variable.
