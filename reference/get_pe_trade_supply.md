# get_pe_trade_supply

Retrieve energy trade supply data for calculating other variables.

## Usage

``` r
get_pe_trade_supply(GCAM_version = "v7.1")
```

## Arguments

- GCAM_version:

  Main GCAM compatible version: 'v7.1' (default), 'v7.2', 'v7.0'.

## Value

\`pe_trade_supply\` global variable.
