# get_transport_stock

Computes the regional transport vehicles stock.

## Usage

``` r
get_transport_stock(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`trn_stock_clean\` global variable.
