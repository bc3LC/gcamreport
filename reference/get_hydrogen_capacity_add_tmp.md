# get_hydrogen_capacity_add_tmp

Calculate added total hydrgoen capacity.

## Usage

``` r
get_hydrogen_capacity_add_tmp(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`hydrogen_capacity_add\` global variable
