# get_capital_formation

Computes Capital Formation data.

## Usage

``` r
get_capital_formation(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`capital_formation_clean\` global variable.
