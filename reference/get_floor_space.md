# get_energy_service_buildings

Get ES buildings.

## Usage

``` r
get_floor_space(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`floor_space_clean\` global variable
