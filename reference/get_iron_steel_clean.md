# get_iron_steel_clean

Retrieve iron steel imports & exports

## Usage

``` r
get_iron_steel_clean(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`iron_steel_clean\` global variable
