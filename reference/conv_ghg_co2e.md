# conv_ghg_co2e

Converts GHG emissions to CO2e.

## Usage

``` r
conv_ghg_co2e(data, GCAM_version = "v7.1", GWP_version = "AR5")
```

## Arguments

- data:

  Dataset containing GHG emissions.

- GCAM_version:

  Main GCAM compatible version: 'v7.1' (default), 'v7.2', 'v7.0'.

- GWP_version:

  Global Warming Potential (GWP) version: 'AR5' (default), 'AR6', or
  'AR4'.
