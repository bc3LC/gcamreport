# get_fe_sector_tmp

Retrieve final energy demand by sector.

## Usage

``` r
get_fe_sector_tmp(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`fe_sector\` and \`fe_sector_raw\` global variables
