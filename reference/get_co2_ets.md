# get_co2_ets

Get World's CO2 ETS emissions query.

## Usage

``` r
get_co2_ets(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`co2_ets_byreg\` and \`co2_ets_bysec\` global variables
