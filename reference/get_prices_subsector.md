# get_prices_subsector

Retreive primary, secondary, and final energy prices.

## Usage

``` r
get_prices_subsector(GCAM_version = "v7.0")
```

## Arguments

- GCAM_version:

  Main GCAM compatible version: 'v7.0' (default), 'v7.1', or 'v6.0'.

## Value

\`prices_subsector_pre\` and \`prices_subsector_biomass\` global
variables
