# get_secondary_solids

Retrieve secondary solids.

## Usage

``` r
get_secondary_solids(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`secondary_solids\` global variable
