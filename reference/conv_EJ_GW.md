# conv_EJ_GW

Converts energy from EJ to GW.

## Usage

``` r
conv_EJ_GW(data, cf, EJ, GCAM_version = "v8.2")
```

## Arguments

- data:

  Dataset containing energy data.

- cf:

  Conversion factor for EJ to GW.

- EJ:

  Amount of energy in EJ.

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.
