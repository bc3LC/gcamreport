# conv_EJ_GW

Converts energy from EJ to GW.

## Usage

``` r
conv_EJ_GW(data, cf, EJ, GCAM_version = "v7.1")
```

## Arguments

- data:

  Dataset containing energy data.

- cf:

  Conversion factor for EJ to GW.

- EJ:

  Amount of energy in EJ.

- GCAM_version:

  Main GCAM compatible version: 'v7.1' (default), 'v7.2', 'v7.0'.
