# get_refliq_bioshare

Get biomass share of feedstocks refined liquids production

## Usage

``` r
get_refliq_bioshare(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`refliq_bioshare\` global variable.
