# get_energy_price_fragmented

Retrieves energy prices fragmented by region and joins them since prices
vary by region.

## Usage

``` r
get_energy_price_fragmented(GCAM_version = "v7.0")
```

## Arguments

- GCAM_version:

  Main GCAM compatible version: 'v7.0' (default), 'v7.1', or 'v6.0'.

## Value

\`energy_price_fragmented\` global variable
