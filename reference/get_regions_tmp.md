# get_regions_tmp

Retrieve regions for carbon price computation. This function fetches the
regions necessary for calculating carbon prices.

## Usage

``` r
get_regions_tmp(GCAM_version = "v7.1")
```

## Arguments

- GCAM_version:

  Main GCAM compatible version: 'v7.1' (default), 'v7.2', 'v7.0'.

## Value

\`regions.global\` global variable.
