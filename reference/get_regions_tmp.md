# get_regions_tmp

Retrieve regions for carbon price computation. This function fetches the
regions necessary for calculating carbon prices.

## Usage

``` r
get_regions_tmp(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`regions.global\` global variable.
