# do_mount_tree

Recursive function to create a nested list from a dataframe.

## Usage

``` r
do_mount_tree(df, column_names, current_column = 1, selec = TRUE, iid = NULL)
```

## Arguments

- df:

  dataset

- column_names:

  names of the columns of the original dataset

- current_column:

  number of the current column

## Value

nested list
