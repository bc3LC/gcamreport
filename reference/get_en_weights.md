# get_en_weights

Get energy items weighted by demand. By region and global.

## Usage

``` r
get_en_weights(GCAM_version = "v7.1")
```

## Arguments

- GCAM_version:

  Main GCAM compatible version: 'v7.1' (default), 'v7.2', 'v7.0'.

## Value

\`en_weights\` and \`en_wld_weights\` global variables
