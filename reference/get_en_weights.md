# get_en_weights

Get energy items weighted by demand. By region and global.

## Usage

``` r
get_en_weights(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`en_weights\` and \`en_wld_weights\` global variables
