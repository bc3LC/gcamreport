# get_ag_weights

Get agricultural items weighted by demand. By region and global.

## Usage

``` r
get_ag_weights(GCAM_version = "v7.1")
```

## Arguments

- GCAM_version:

  Main GCAM compatible version: 'v7.1' (default), 'v7.2', 'v7.0'.

## Value

\`ag_weights\` and \`ag_wld_weights\` global variables.
