# get_ag_weights

Get agricultural items weighted by demand. By region and global.

## Usage

``` r
get_ag_weights(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`ag_weights\` and \`ag_wld_weights\` global variables.
