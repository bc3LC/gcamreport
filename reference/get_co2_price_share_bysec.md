# Get CO2 Price Share

Retrieves the CO2 price share of each region or sector compared to the
total CO2 price.

## Usage

``` r
get_co2_price_share_bysec(GCAM_version = "v7.1")
```

## Arguments

- GCAM_version:

  Main GCAM compatible version: 'v7.1' (default), 'v7.2', 'v7.0'.

## Value

Global variable \`co2_price_share_bysec\` containing CO2 price shares by
sector.
