# get_food_weights

Get food items weighted by demand. By region and global.

## Usage

``` r
get_food_weights(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`food_weights\` and \`food_wld_weights\` global variables.
