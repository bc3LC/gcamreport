# get_income

Compute share of total income my decile

## Usage

``` r
get_income(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`income_clean\` and \`income_raw\` global variables.
