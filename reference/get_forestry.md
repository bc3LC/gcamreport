# get_forestry

Computes Forestry production and demand

## Usage

``` r
get_forestry(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`forestry_demand_clean\` and \`forestry_production_clean\` global
variables.
