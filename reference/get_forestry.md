# get_forestry

Computes Forestry production and demand

## Usage

``` r
get_forestry(GCAM_version = "v7.1")
```

## Arguments

- GCAM_version:

  Main GCAM compatible version: 'v7.1' (default), 'v7.2', 'v7.0'.

## Value

\`forestry_demand_clean\` and \`forestry_production_clean\` global
variables.
