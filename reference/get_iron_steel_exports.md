# get_iron_steel_exports

Retrieve iron steel production.

## Usage

``` r
get_iron_steel_exports(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`iron_steel_exports\` global variable
