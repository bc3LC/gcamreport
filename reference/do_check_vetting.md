# do_check_vetting

Verify vetting and produce plot.

## Usage

``` r
do_check_vetting(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

A message confirming the success of the vetting process.
