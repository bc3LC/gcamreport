# get_goods_trade

Compute net exports of all goods measured in monetary quantities:
materials-net-export + capital-net-export + energy-net-export

## Usage

``` r
get_goods_trade(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`goods_trade_clean\` global variables.
