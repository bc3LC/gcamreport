# get_elec_gen_tech

Retrieve electricity generation.

## Usage

``` r
get_elec_gen_tech(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`secondary_energy_clean\` and \`secondary_energy_raw\` global variables
