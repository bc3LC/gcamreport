# get_cf_iea_tmp

Calculate cf for existing capacity checking global existing capacity
from IEA.

## Usage

``` r
get_cf_iea_tmp(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`cf_iea\` global variable
