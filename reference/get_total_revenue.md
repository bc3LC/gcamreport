# get_total_revenue

Compute total revenue: total production \* global price.

## Usage

``` r
get_total_revenue(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`total_revenue\` global variable
