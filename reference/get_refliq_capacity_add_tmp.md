# get_refliq_capacity_add_tmp

Calculate added total refined liquids electricity capacity.

## Usage

``` r
get_refliq_capacity_add_tmp(GCAM_version = "v7.1")
```

## Arguments

- GCAM_version:

  Main GCAM compatible version: 'v7.1' (default), 'v7.2', 'v7.0'.

## Value

\`refliq_capacity_add\` global variable
