# get_co2_tech_nobio_tmp

Retrieves the non-bio CO2 emissions query by sector and technology.

## Usage

``` r
get_co2_tech_nobio_tmp(GCAM_version = "v7.1")
```

## Arguments

- GCAM_version:

  Main GCAM compatible version: 'v7.1' (default), 'v7.2', 'v7.0', or
  'v6.0'.

## Value

\`co2_tech_nobio\` global variable.
