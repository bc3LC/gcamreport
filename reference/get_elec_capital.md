# get_elec_capital

Calculate capital cost of a newly installed plants.

## Usage

``` r
get_elec_capital(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`elec_capital_clean\` global variable
