# get_transport_sales

Computes the regional transport vehicles sales.

## Usage

``` r
get_transport_sales(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`trn_sales_clean\` global variable.
