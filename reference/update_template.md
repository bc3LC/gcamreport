# update_template

Update the template file by incorporating new reported variables and
removing unreported ones.

## Usage

``` r
update_template(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

Updated template saved as both .rda and .csv files in the
\`inst/extdata\` folder.
