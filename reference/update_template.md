# update_template

Update the template file by incorporating new reported variables and
removing unreported ones.

## Usage

``` r
update_template(GCAM_version = "v7.1")
```

## Arguments

- GCAM_version:

  Main GCAM compatible version: 'v7.1' (default), 'v7.2', 'v7.0'.

## Value

Updated template saved as both .rda and .csv files in the
\`inst/extdata\` folder.
