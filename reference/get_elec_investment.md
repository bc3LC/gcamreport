# get_elec_investment

Calculate electricity investment = annual capacity additions \* capital
costs.

## Usage

``` r
get_elec_investment(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`elec_investment_clean\` global variable
