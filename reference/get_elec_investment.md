# get_elec_investment

Calculate electricity investment = annual capacity additions \* capital
costs.

## Usage

``` r
get_elec_investment(GCAM_version = "v7.1")
```

## Arguments

- GCAM_version:

  Main GCAM compatible version: 'v7.1' (default), 'v7.2', 'v7.0'.

## Value

\`elec_investment_clean\` global variable
