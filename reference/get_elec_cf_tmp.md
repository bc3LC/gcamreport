# get_elec_cf_tmp

Computes future capacity estimates using GCAM.

## Usage

``` r
get_elec_cf_tmp(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`elec_cf\` global variable
