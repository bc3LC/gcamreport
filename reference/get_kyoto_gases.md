# get_kyoto_gases

Get sectorial GHG emissions.

## Usage

``` r
get_kyoto_gases(GCAM_version = "v7.1", GWP_version = "AR5")
```

## Arguments

- GCAM_version:

  Main GCAM compatible version: 'v7.1' (default), 'v7.2', 'v7.0'.

- GWP_version:

  Global Warming Potential (GWP) version: 'AR5' (default), 'AR6', or
  'AR4'.

## Value

\`kyoto_gases_clean\` global variable.
