# get_pe_trade_prod

Retrieve energy trade data.

## Usage

``` r
get_pe_trade_prod(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`pe_trade_prod\` global variable.
