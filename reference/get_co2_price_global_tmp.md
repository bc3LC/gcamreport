# get_co2_price_global_tmp

Retrieve global co2 price.

## Usage

``` r
get_co2_price_global_tmp(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`co2_price_global\` global variable
