# do_bind_results

Binds results and saves them to an output file.#'

## Usage

``` r
do_bind_results(GCAM_version = "v8.2", all_tier1 = F)
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

- all_tier1:

  If \`TRUE\` (not default), introduce all Tier 1 Variables (as 0) in
  the standardized report.

## Value

Saved results in an output file.
