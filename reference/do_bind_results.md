# do_bind_results

Binds results and saves them to an output file.#'

## Usage

``` r
do_bind_results(GCAM_version = "v7.1", all_tier1 = F)
```

## Arguments

- GCAM_version:

  Main GCAM compatible version: 'v7.1' (default), 'v7.2', 'v7.0'.

- all_tier1:

  If \`TRUE\` (not default), introduce all Tier 1 Variables (as 0) in
  the standardized report.

## Value

Saved results in an output file.
