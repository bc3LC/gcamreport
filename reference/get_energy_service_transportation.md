# get_energy_service_transportation

Retrieve transport service.

## Usage

``` r
get_energy_service_transportation(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`energy_service_transportation_clean\` global variable
