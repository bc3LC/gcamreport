# get_energy_service_transportation

Retrieve transport service.

## Usage

``` r
get_energy_service_transportation(GCAM_version = "v7.1")
```

## Arguments

- GCAM_version:

  Main GCAM compatible version: 'v7.1' (default), 'v7.2', 'v7.0'.

## Value

\`energy_service_transportation_clean\` global variable
