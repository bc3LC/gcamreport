# get_water_withdrawals

Retrieves the water withdrawals.

## Usage

``` r
get_water_withdrawals(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`water_withdrawals_clean\` global variable.
