# get_water_consumption

Retrieves the water get_water_consumption

## Usage

``` r
get_water_consumption(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`water_consumption_clean\` global variable.
