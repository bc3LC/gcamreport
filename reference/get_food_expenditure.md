# get_food_expenditure

Computes food expenditure.as the share of the total expenditure by
decile

## Usage

``` r
get_food_expenditure(GCAM_version = "v7.1")
```

## Arguments

- GCAM_version:

  Main GCAM compatible version: 'v7.1' (default), 'v7.2', 'v7.0'.

## Value

\`food_expenditure_per_clean\` global variable.
