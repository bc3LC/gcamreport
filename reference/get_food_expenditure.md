# get_food_expenditure

Computes food expenditure.as the share of the total expenditure by
decile

## Usage

``` r
get_food_expenditure(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`food_expenditure_per_clean\` global variable.
