# get_fert_consumption

Computes Fertilizer consumption

## Usage

``` r
get_fert_consumption(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`fert_consumption_clean\` global variable.
