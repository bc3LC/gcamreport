# get_total_investment

Calculate investment of resource production + extraction.

## Usage

``` r
get_total_investment(GCAM_version = "v8.2")
```

## Arguments

- GCAM_version:

  Name of the GCAM compatible version. Run \`available_GCAM_versions()\`
  to see the list of supported options.

## Value

\`total_investment_clean\` global variable
