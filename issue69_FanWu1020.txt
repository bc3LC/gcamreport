Doing some debug, we detected a small error. It has been fixed and now it should run smoothly! Thanks for reporting it!!

Nevertheless, keep in mind that when creating a GCAM project, you decide which queries do you load. If you did it with `gcamreport`, the package automatically selected the necessary queries for the desired variables at that point. If you load a project through the package, there is a function that automatically drops all the non-required queries and regions, so reduce the data weight and make it more manageable. Thus, if you want to standardize other variables (than the once indicated when creating the project) and the necessary queries are not there, you might result in an empty project.
